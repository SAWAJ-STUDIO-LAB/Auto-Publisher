# 🎬 Sawaj Studio Video Requirements & Asset Hub

This module contains shared requirements, system setup configurations, global fonts, logos, and media watermark assets for all video generators:

1. **FB/IG Story Video Generator** (9:16 Vertical Story)
2. **FB/IG/YT Short Video Generator** (9:16 Shorts/Reels)
3. **FB/YT Long Video Generator** (16:9 Landscape Video)
