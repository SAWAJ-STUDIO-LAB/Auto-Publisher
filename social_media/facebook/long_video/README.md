# 🎥 Facebook Long Video

Automated Facebook Long video (5-15 minutes) with 3-language display.

## Features
- Hadith fetch (multi-API, 400-1800 word filter)
- Hindi translation (DeepL + AI)
- Voice (ElevenLabs + edge-tts)
- Background music + video
- 3-Language word-by-word display
- Intro (Bismillah + Logo)
- Outro (JazakAllah + CTA)
- Google Drive backup
- Facebook Long upload
- Combined Telegram report

## Duration
5-15 minutes (voice) + 2s intro + 2s outro
