# 🎬 Facebook Short Video

Automated Facebook Short video (1-3 minutes) with 3-language display.

## Features
- Hadith fetch (multi-API, 100-700 word filter)
- Hindi translation (DeepL + AI)
- Voice (ElevenLabs + edge-tts)
- Background music + video
- 3-Language word-by-word display
- Intro (Bismillah + Logo + Gold line)
- Outro (JazakAllah + CTA)
- Sparkles + Progress bar
- Google Drive backup
- Facebook Short upload
- Combined Telegram report

## Duration
1-3 minutes (voice) + 2s intro + 2s outro
